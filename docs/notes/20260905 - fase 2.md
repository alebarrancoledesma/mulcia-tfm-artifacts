\## Problemas



Adaptamos instancias a salir todo de l0 y ciertas necesidades de mas de una unidad en cada destino (CVRP-like)



Adaptamos de manera que se asegura factibilidad (l0 alcanzable de alguna forma por el resto de nodos). asi podemos coger cualquier problema de los ejemplos y adaptarlo a esta casuistica mas de reparto desde almacen.



Hasta ahora abierto.



Se crea entrada en suites.py con la SUITE para tire de esos archivos al hacer el prompt.



Comando para generar heurística LLM:



```powershell

uv run llm-heuristics.py --framework deepseek --model deepseek-v4-flash --domain cvrp-strips --heuristic-name CvrpStripsHeuristic --heuristic-file cvrp-strips-heuristic.py --no-thinking

```



Comando para generar solución a partir de heurísticas:

```powershell

uv run src/pyperplan/pyperplan.py -s gbfs\_early\_goal\_test -H hff benchmarks/cvrp-strips/testing/easy-p01-open.pddl

```



Para generada con LLM



```powershell

uv run src/pyperplan/pyperplan.py -s gbfs\_early\_goal\_test -H cvrp-strips-heuristic.py benchmarks/cvrp-strips/testing/easy-p01-open.pddl

```
